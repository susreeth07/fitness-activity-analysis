# Daily Activity Analysis Summary

## Dataset

The main activity dataset contains 940 participant-day activity records.

## Average Daily Steps

The average TotalSteps is 7,637.91 steps.

## Average Daily Calories Burned

The average Calories value is 2,303.61 kcal.

## Low-Activity Records

The first quartile (Q1) of TotalSteps is 3,789.75 steps.

Participant-day records below this threshold are classified as low-activity records.

Number of low-activity records: 235.

## Sleep and Activity

The activity and sleep datasets were matched using participant ID and date.

The correlation between sleep duration and total steps was approximately -0.19, indicating a weak negative linear relationship in the matched records.
